# 艾露猫合法性与配信任务

## 艾露猫规则从哪里来

Dex SQLite 有随从装备和随从队奖励表。编辑用的行动 ID、技能 ID、固有能力和生成组合来自游戏原生表。Qt 编辑器把同一批表生成了中英文 CSV、SQLite 及原始规则 JSON。Cotto 和旧 C# 编辑器的 ID 与槽顺序可用于交叉检查。记忆消耗和随等级变化的槽位数，采用 GU 项目从运行时表读出的数据。 [Dex 结构](../README.md) · [Qt 数据来源](../../saveEditor/mhgu-xx-se/data/README.md) · [原生表导出](../../saveEditor/mhgu-xx-se/tools/reference/palico_native_rules.json) · [GU 运行时记录](../../saveEditor/MHGU-Save-editor/docs/11-save-map.md#palico-records)

静态检查了用户给的 GU 与 XX 参考程序。它们是 .NET Framework 4.0 程序，文件里的版本分别是 1.0.3 和 1.1.0。GU 版本的 `CatsForm` 分别处理行动和技能的类型切换，内置文本含 A/B/C 和「可习得技」。它也有单个任务导出入口 `DLCForm.bttnOutputTheQuest_Click`。网页按自己的布局组织相同概念。 [参考目录](<D:/BaiduNetdiskDownload/存档转换/存档转换/3DS MHXX存档转NS MHGU存档>)

网页以记录内 `+0x54`、`+0x56` 的编号查行动和技能组合，用 `+0x55`、`+0x57` 核对有效长度。固有行动、准固有、共通行动和固有被动由倾向决定。生成栏严格按 A/B/C 匹配，传授栏接受可传授项目，配信专属技能还要求当前角色的猫队已有来源。有效栏以外的行动和技能分别填 57 与 96。有效范围内的传授空位也可记录为 0 或对应的 57、96，样本里的领导猫就使用了行动 57。更换组合时保留原有固有栏，尽量沿用符合新组合的已学项目，并从已装备栏移除不再会的项目。

勾选表示当前装备，取消勾选时还会保留在已学栏。行动容量为等级表中的空槽数加 2，装备「支援行动＋1」再加 1。技能按各自消耗累加，消耗未知的组合无法写入。配信猫保留配信组合，普通猫的行动和技能按列独立校验。某列的特殊组合只锁定该列的已学栏。GU 有实测与运行时证据，XX 的生成结构有日版原生表支持，新增编辑仍需实际游戏回灌。

## 配信任务存放位置

以下地址都从游戏正文起点算。带头 Switch 文件再加 `0x24`。

| 版本 | 活动任务区 | 挑战任务区 | 挑战固定配装 | 单任务格 |
|---|---:|---:|---:|---:|
| Switch GU | `0xF875` | `0x127875` | `0x176475` | `0x1C00` |
| Switch XX 与 3DS XX | `0xF874` | `0xD7874` | `0x10FC74` | `0x1400` |

每版有 160 个活动格、45 个挑战格，另有 45 个 `0x800` 字节的挑战配装格。任务格开头是编号和 ARC 大小，后跟 ARC。末尾 256 字节原样保留。GU 还有一个已知的账号值落在任务区的间隙，导出整包时清除这 8 字节，导入时保留目标原值。 [GU 存档图](../../saveEditor/MHGU-Save-editor/docs/11-save-map.md#downloaded-quests--block-b) · [含配信的公开存档](https://github.com/FurkanM7/All-Event-Quests-and-Palicoes-MHXX-MHGenU/tree/2d7938f)

整包 `.mhqpack` 供网页导入导出。12 字节头部后是 32 字节任务位图与下载标记，再接三段原生任务区。导入时检查版型、ARC 目录、编号、位图数量和挑战配装，对应到目标的任务区。两个 XX 样本剥掉 Switch 头后，整个配信区逐字节相同，可以互导。GU 使用独立包。网页也可直接从同版 `system` 提取任务区用于导入。

## 自建任务

选择一条已安装任务作为模板，可调整时限、猫车次数、契约金、主副任务奖金、HR 点数，各语言的名称、委托说明和目标文字，以及新增、替换或移除可编辑的道具报酬。写回时保留模板的任务 ID、地图、目标和刷怪资源。更改目标文字只改显示。可以另外导出 ARC 并在同版本的同编号任务格替换。 [上游任务字段、GMD、ARC 读写](https://github.com/Fexty12573/MHGUQuestEditor/tree/001abf8/MHGUQuestEditor/Resources)

全新任务 ID 还涉及游戏的任务目录、配信目录和引用资源。现有实现通过模板 ID 让存档位图和目录仍有对应项。改过的 ARC、整包和重新导出的 `system` 已通过网页回读，修改版任务的游戏加载、接取和结算仍需在对应版本单独实测。存档原有的 256 字节下载尾部按字节保留。

## 验证

在 `webapp` 下执行 `npm test`。设置 `MHXX_DLC_FIXTURES` 指向公开样本解包后包含三个 `* Savedata` 目录的文件夹，可另跑三版原档逐条解包和整包逐字节往返。样本中 GU 有 165 条，两个 XX 各有 180 条。网页不需要样本才能运行。
